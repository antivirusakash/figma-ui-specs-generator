# Customer Vision: "Hal" (AI Twin)

> **Load when**: product vision, roadmap, phased rollout, customer expectation

---

## Productivity Trajectory

| State | Multiplier | Enabler |
|-------|------------|---------|
| Baseline (2 yrs ago) | 1x | Manual |
| Current (ChatGPT) | 2x | Always-on AI colleague |
| Phase 1 (Hal) | 4x | Full context ingestion |

---

## Phase Model

### Phase 1: Ingest Everything
**Inputs:**
- Meetings (Granola-like)
- Wearable recorder (Plaud-like)
- Emails, texts, Slack, WhatsApp, Signal

**Output:** Thought partner + project manager on everything

### Phase 2: Clone Creation
- AI interviews user extensively
- Trains on all ingested data
- Smarter than user, better memory
- Avatar that's "scarily similar"

### Phase 3: Active Participation
- Joins meetings as full participant (not just recorder)
- Answers questions on demand
- Contextualizes historical knowledge
- Can represent user when unavailable

**Ultimate:** AI takes meetings solo; user fully delegates

---

## Design Implications

| Insight | Implication |
|---------|-------------|
| Phased value unlock | Design for progressive capability reveal |
| "Full participant" expectation | Meeting proxy must contribute, not just observe |
| Multi-source ingestion | Unified context model across silos |
| Clone as smarter self | Frame as augmentation, not automation |
| Delegation comfort grows over time | Progressive autonomy UX |

---

## Adoption Signals

- Recorder in meetings: "seemed off" → "norm just a couple of years later"
- Wearable recorder: "very weird if I wore it tomorrow" → "standard in couple years"
- AI representation: "sounds weird" → "part of our future"

**Pattern:** User acknowledges social friction dissolves rapidly once value proven.
