# Hierarchy & Layout Knowledge

---

## Mental Models for Hierarchy

| Model | Application |
|-------|-------------|
| Conversation | "What would I say first?" — order of importance = speaking order |
| Task | "What does user need NOW vs LATER?" — immediate prominent, secondary hidden |

---

## Hierarchy Tools (In Order of Impact)

1. **Position** — Top-left gets seen first (F/Z patterns)
2. **Size** — Larger = more important
3. **Contrast** — High contrast draws attention
4. **Whitespace** — Isolation = importance
5. **Weight** — Bold/heavy = emphasis
6. **Color** — Use sparingly for emphasis
7. **Alignment** — Breaks in alignment draw eye
8. **Proximity** — Related items grouped together
9. **Repetition** — Consistency establishes pattern

---

## Reading Patterns

| Pattern | Use For |
|---------|---------|
| F-pattern | Text-heavy content (articles, documentation) |
| Z-pattern | Sparse content (landing pages, cards, marketing) |
| Gutenberg | Dense, uniform content (data tables) |

---

## Hierarchy Quick Checks

- What's the first thing users see?
- Is the primary action obvious?
- Can users scan without reading?
- Are there competing focal points?
- Does the hierarchy support the task?

---

## Common Hierarchy Mistakes

| Mistake | Problem |
|---------|---------|
| Everything bold | Nothing stands out |
| Multiple CTAs equal weight | User doesn't know what to do |
| Important content below fold | Assumes user will scroll for it |
| Decorative elements compete | Distraction from content |
