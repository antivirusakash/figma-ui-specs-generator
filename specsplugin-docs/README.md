# Specs Plugin Documentation

This is the locally scraped documentation from [specsplugin.com](https://www.specsplugin.com).

> Automate production of page and component design specifications ("specs") of selected components, instances and frames. The output is useful for design-dev handoff, auditing design work, and critique. Originally known as EightShapes specs.
