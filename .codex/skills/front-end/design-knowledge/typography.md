## What Breaks Typography Texture

| Issue | Problem |
|-------|---------|
| Inconsistent line-height across contexts | Dense here, airy there without reason |
| Too many font weights in close proximity | Regular, medium, semibold, bold competing |
| Mixing non-harmonizing type scales | Arbitrary sizes that don't feel related |

---

## Typography Discipline

- Max 2-3 font weights per view
- Type scales must feel mathematically related
- Line-height should be consistent within context type

---

## Hierarchy Through Type

| Tool | Use |
|------|-----|
| Size | Primary differentiator |
| Weight | Secondary differentiator |
| Color | Tertiary (muted for secondary text) |

**Anti-pattern**: Using color as primary hierarchy tool (accessibility issues, inconsistent)

---

## Quick Checks

- Can you identify the 3 most important text elements?
- Are there more than 3 font weights visible?
- Does line-height feel consistent?
