# Visual Perception

> **Pairs with**: General (applies everywhere)
> **Load when**: `visual`, `alignment`, `spacing feels off`, `looks wrong`, `polish`, `premium`

---

## The "Off" Detector

When a UI feels wrong but you can't articulate why, check:

1. **Rhythm/spacing inconsistency** — Elements don't follow predictable visual rhythm
2. **Hierarchy confusion** — Eye doesn't know where to go; competing focal points
3. **Density mismatch** — Some areas cramped, others empty without reason

---

## Optical Alignment Rules

| Situation | Rule |
|-----------|------|
| Circular/irregular shapes | Nudge for visual centering, not mathematical |
| Text + containers | Baselines trump bounding box alignment |
| Large elements | Need more breathing room offset (visual weight compensation) |

---

## Premium Signals

| Signal | Detail |
|--------|--------|
| Consistent, generous whitespace | Room to breathe everywhere |
| Typography hierarchy via size/weight only | Monochromatic text hierarchy, not color |
| Subtle shadows and borders | Soft edges, not harsh dividers |
| Restraint in color usage | Fewer colors, more intentional |

---

## Weight Perception

UI "feels heavy" when:
- Visual density and saturation is high (dark colors, filled shapes)
- Cognitive load to understand state is high (complex states)

**Lightening strategies:**
- More whitespace
- Reduce saturation
- Simplify states
- Use outline instead of filled icons/buttons
