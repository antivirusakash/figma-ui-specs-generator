# Copy & Microcopy Knowledge

---

## Writing Style

| Rule | Example |
|------|---------|
| Active voice | "Install the CLI" not "The CLI will be installed" |
| Title Case | For headings and buttons (Chicago style) |
| Numerals for counts | "8 deployments" not "eight deployments" |
| Second person | "You" not "I" or "We" |
| `&` over "and" | Where space-constrained |

---

## Button Labels

| Principle | Example |
|-----------|---------|
| Verb + object | "Save changes" not "Save" |
| Specific labels | "Save API Key" not "Continue" |
| Outcome over action (high stakes) | "Permanently delete" reveals consequence |
| Match user's mental model | "Publish" not "Set visibility to public" |
| Shorter until clarity suffers | Trim words, not meaning |

---

## Error Messages (All Four Required)

| Requirement | Example |
|-------------|---------|
| Says what went wrong specifically | "Password must be 8+ characters" not "Invalid" |
| Suggests what to do next | "Try again" or "Contact support" |
| Uses human language | "We couldn't save" not "Error 500" |
| Appears where the problem is | Inline at field, not just form summary |

---

## Microcopy Checklist

- [ ] Is it specific enough to act on?
- [ ] Does it use the user's vocabulary?
- [ ] Is it as short as possible without losing clarity?
- [ ] Does it avoid jargon and technical terms?
- [ ] Does it include fix/next step (not just problem)?

---

## Common Copy Mistakes

| Mistake | Better |
|---------|--------|
| "Invalid input" | "Email must include @" |
| "Error" | "Couldn't save — try again" |
| "Submit" | "Create account" (specific action) |
| "OK" / "Cancel" | "Delete" / "Keep" (specific outcomes) |
| "Continue" | "Save API Key" (specific outcome) |
| Passive voice | Active voice |
| First person | Second person |
