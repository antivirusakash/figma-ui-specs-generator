# UX Laws Reference

> **Load when**: `ux law`, `hick`, `fitts`, `jakob`, `miller`, `doherty`, `user behavior`, `psychology`

---

## Core Laws

| Law | Application |
|-----|-------------|
| **Jakob's Law** | Use familiar patterns users know from other products |
| **Hick's Law** | Reduce choices to speed decisions |
| **Fitts's Law** | Larger targets = easier to hit. 44px minimum touch. |
| **Miller's Law** | Chunk information into 5-9 items |
| **Doherty Threshold** | Response < 400ms feels instant |
| **Zeigarnik Effect** | Show progress to encourage completion |
| **Occam's Razor** | Simplest solution wins |

---

## Problem → Law Mapping

| Problem | Apply |
|---------|-------|
| Too many options | Hick's Law — reduce choices |
| Users confused | Jakob's Law — use familiar patterns |
| Hard to click/tap | Fitts's Law — increase target size |
| Overwhelming list | Miller's Law — chunk into groups |
| Feels slow | Doherty Threshold — optimize or show perceived progress |
| Users abandoning | Zeigarnik — show completion progress |
| Over-engineered | Occam's Razor — simplify |
